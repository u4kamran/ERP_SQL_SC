Private Sub CmdClear_Click()

On Error GoTo TrapError

   If nCounter >= 2 Then

      If Not MsgBox("Clearing voucher, Are you sure ?", vbInformation + vbYesNo, cSelFormId) = vbYes Then

            Exit Sub

      End If

   End If

   Call clearform

Exit Sub

TrapError:

    Call ShowError(lngError, Me.Caption)

End Sub
